# Design Preferences

## Favorite CSS Default

Use the Bacari Shift Trader dark blue theme as the default starting point for new projects in this workspace.

- Page background: `#080f1c`
- Card/panel background: `#101827` or `#111b2e`
- Selected/hover panel background: `#132033`
- Primary text: `#eef6ff`
- Soft text: `#c6d8ef`, `#9fb5d1`
- Primary blue accent: `#60a5fa`
- Strong action blue: `#3b82f6`
- Hover/action blue: `#2563eb`
- Disabled/dim background: `#162033`
- Borders: `rgba(147, 197, 253, 0.16)` to `rgba(147, 197, 253, 0.28)`

Style notes:
- Dark mode by default.
- Use blue accents instead of red.
- Keep UI practical, clean, and readable.
- Prefer squared or lightly sharp panels over very rounded cards.
- Use the Bacari Shift Trader CSS as the reference implementation:
  `src/BacariShiftTrader/BacariShiftTrader.css`
